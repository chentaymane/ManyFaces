Android engine setup

This boots a real Android device in the official emulator — a genuine Chrome-for-Android engine, not a fingerprint spoof. It's free. First-time setup downloads the Android SDK + a system image (a few GB), a small mirror app (scrcpy) that displays the phone in a clean window with real touch, and, if needed, a Java runtime. The device runs headless with hardware GPU and is shown through the mirror. The first boot takes ~1–2 min; after that it quickboots in seconds. Each device needs ~4–5 GB free disk.
